# Project Notes

Keep this file compact and self-improving. When a task reveals a durable project rule, naming convention, file location, bug pattern, or balance/design intent that would help future agents reach the correct outcome faster, add or refine a short note here. Avoid one-off details, long explanations, and anything that only helps the current edit.

- This is a Dota 2 custom game addon with very large KV and localization files. Search narrowly with `rg -n -C` for ability names, tooltip tokens, or talent names instead of reading whole files.
- Common locations: Lua ability scripts in `scripts/vscripts/abilities/...`, ability KV in `scripts/npc/npc_abilities_custom.txt`, English tooltips in `resource/addon_english.txt`.
- Mirror new game-mode modifiers' `LinkLuaModifier` registrations in `scripts/vscripts/addon_init.lua` so the client can resolve them too.
- Patch notes live in `patch note.txt`; use informal bullets and visible item/ability names. `---` separates versions pushed live, not individual edits or chats. Consolidate unpublished work in the current final block before its trailing `---`, describing only the final player-visible changes versus the last live version. Omit temporary diagnostics, reverted experiments, and corrections to changes that never went live; preserve the user's trimmed notes.
- At the start of a new chat, read the patch-note tail and identify the current patch session. A new chat/day alone does not start a release block; the user's "new day", "new patch session", or explicit push/new-version instruction establishes the boundary. The current unpublished session starts with the team-wipe countdown change during the Juggernaut Sword Master challenge. Update this pointer when the user pushes or starts the next patch.
- Prefer normal `ability:GetSpecialValueFor(...)` when the KV links talents directly in the `AbilityValues` block, for example: `"crit_chance" { "value" "2 2 3 4 5" "special_bonus_unique_pa_coup_de_grace_crit_chance" "5" }`.
- `GetTalentSpecialValueFor` exists in older Lua files, but newer correctly-written KV can make it unnecessary.
- Super Scepter is custom. Lua usually checks it with `local has_ss = caster:HasModifier("modifier_super_scepter")`; patch notes may call it `Super Scepter` or `SS` if that matches nearby style.
- The underdog list is controlled by `UnitLabel` in `scripts/npc/npc_heroes_custom.txt`. Add/remove heroes by uncommenting/commenting `"UnitLabel" "no_underdog"`; `fix_atr_for_hero2` in main(aohgamemode.lua) filters this and gives the permanent post-level-34 buff modifier.
- Tooltip custom section colors: `#DE3163` Super Scepter, `#0094FF` Aghanim's Scepter, `#F70707` Challenge Boss, `#2AD563` UP item sections, `#86C91F` Extra Passive, `#F17C26` Info, `#FFA32B` Exclusive label. Keep existing hero/exclusive colors when editing nearby tooltip text.
- Top item stat bonuses use `+$label` (flat) or `%+$label` (percentage), with custom text in `dota_ability_variable_label`. A plain `%LABEL:` special-value tooltip puts the stat at the bottom instead.
- For multi-line Super Scepter or ability descriptions, use `<br>` between numbered items (e.g. `1. ...<br>2. ...`) without extra blank lines or `\n` paragraph breaks to avoid excessive vertical spacing in the UI.
- Some heavy visual effects respect `_G._effect_rate`; common pattern is `local randomSeed = math.random(1, 100)` then only play the effect when `randomSeed <= _G._effect_rate`. Tooltip info often tells host to use `-effect_rate 1-20`.
- Be careful with unrelated context in the big files. Keep edits scoped to the exact ability, tooltip, or talent being worked on.
- `scripts/vscripts/hack/precache_resource.lua` is used to directly write and precache particle effects, models, or sound resources that do not load in the normal way on local server testing.
- Random skill books use `scripts/vscripts/hack/item_random_get_ability_onlvl.lua` and related scripts. Native abilities added mid-match can need individual precache entries for effects referenced only by the engine.
- `lib/healing_guard.lua` installs the global healing filter, ON by default. Reject negative/invalid heals before entity lookup; cap accepted heals to min(max HP, 1M, 100M-current HP). The 100M boundary does not change max HP. Keep the per-heal path free of logs, counters, allocations, and timers for high attack rates. `-healguard` reports status; host on/off requires Tools/cheats. The ON/OFF reproduction intercepted negative overflow heals; direct `SetHealth` bypasses the filter. See `tools/tests/healing_guard_ingame.md` for coverage tests.
- `modifier_generic_handler.lua` separately caps custom lifesteal at 400,000 before engine amplification. Vanilla lifesteal talents (including Drow's `special_bonus_spell_lifesteal_6`) bypass that custom handler.
- Modified innate abilities live in `scripts/npc/inate_skills/inate_ab_skills.txt` (included via `npc_abilities_override.txt`). If a Dota update breaks an innate override, compare against vanilla files referenced via `NPC vanilla\scripts\npc\heroes`.
- Refresh `NPC vanilla` reference text files with `python tools/update_vanilla_reference.py` after a Dota patch. Use `--check` to verify the snapshot against `pak01_dir.vpk`.
- `modifier_atr_fix.lua` offsets native Intelligence magic resistance against 30% base. Dota 7.42 uses 0.125 percentage points per Intelligence. Keep the game-mode zero override commented while this offset runs.
- Heroes reach levels ~100-120 in late game (70+ min rounds), so per-level scaling values (e.g. per-level attack speed or damage additions) must be kept modest to prevent extreme numbers.
- For balance suggestions, use `https://conrelly.com/items_data.php`, the Heroes Database from match history, and `scripts/vscripts/played_heroes.lua` to find moderately used picks. Prioritize solo waves, bosses, and gods. Check endgame caps and existing build interactions before proposing stat buffs. The global attack-speed cap is 1100 (`aohgamemode.lua`).
- Spirit Guardian shares `items/staff_of_light.lua` with Staff of Light tiers. Its damage level multiplier is `100 + (level - 100) * 10` above level 100 for both Snowball and Super Scepter Intelligence damage; extra-stack chance still uses actual hero level.
- Broken Wings counts both feather types toward Divinity and caps stat bonuses at 50 combined. Power spends regular feathers. Divinity Feathers survive death and clear when Divinity ends. Damage limit coefficients live in the item KV.
- Upgraded Radiance Armor forms share `items/custom/radiance_armor_damage.lua` for the full burn multiplier at the caster's current level. It stacks with Power Unlock and feeds Challenge Boss healing where the burn already heals.
- Only override the specific abilities or values being modified in `npc_abilities_override.txt` (or `inate_ab_skills.txt` for innates). Avoid duplicating entire hero or ability blocks to prevent falling behind vanilla Dota updates.
- Native point abilities still need a cursor position when changed to `NO_TARGET`. God's Rebuke's cast modifier supplies a point based on the caster's facing.
- Mars's Spear and Arena share `abilities/hero_mars/mars_strength_damage.lua` for effective-level Strength scaling. Arena's Super Scepter autocast switches only the spear spell damage to Pure at 10%.
- Spear of Mars keeps its original Strength talent ID for double damage. Aghanim's Shard keeps the cast spread for the first 20% of travel, then each spear searches from its current position and turns using `UpdateLinearProjectileDirection`. Retarget on impact within remaining travel and skip previous hits. Shard removes skewer and pin. Drive the glow and smoke with a level control-point 3 transform because the stock launch particle keeps its initial velocity.
- Panorama source files (`.xml`, `.js`, `.css`) are edited in `D:\SteamLibrary\steamapps\common\dota 2 beta\content\dota_addons\heroattackon_tools\panorama\`. Workshop Tools compiles them into `dota 2 beta\game\dota_addons\heroattackon_tools` (as `.vxml_c` / `.vjs_c`). Note: the content folder has some extra/legacy files, so use it for active source edits rather than a 100% full replacement reference.
- Compact HUD numbers use the native `stats`, `stragiint`, and `Tooltips` panels. Ship the compiled `custom_ui_manifest.vjs_c` with its bindings in `panorama/localization/addon_english.txt`. Give the three portrait totals equal width so the last attribute cannot be squeezed out. Keep the native Alt split layout.
- Game update workflow: Updates are pushed by copying files to the production folder `hero_attack_on_gods` along with updated `patch note.txt` entries (which are also posted to the map's Discord channel).
- Autocast & Multi-Autocast (`mjz_bristleback_quill_spray_autocast*.lua`): Secondary sub-abilities, release/stop triggers, and channeled toggles (e.g. `hw_sharpshooter_release`, `dawnbreaker_land`, `faceless_void_time_walk_reverse`) must be in the `NoAutocast` ignore list to avoid premature cancellation or slot desyncs. The user has deep domain insight into autocast ignore lists and mechanics.
- Precache / `CLoadingResource` limit: Source 2 enforces a strict 32,767 capacity on precached resources (`GrowCount` assertion crash). NEVER use `PrecacheResource("particle_folder", ...)` or `"particle_folder"` in unit/ability KV precache blocks; batch folder scanning enumerates 20,000+ files and exhausts handles. Always precache individual `.vpcf`, `.vmdl`, and `.vsndevts` files through `scripts/vscripts/hack/precache_resource.lua`.
- File-scope initialization: Never make HTTP calls (`CreateHTTPRequestScriptVM`) or spawn thinker entities during root script evaluation (`require` time / `ss_waitingforgamesessionmanifest`). Subsystems return `nil` or crash before the map/entities are active; delay them to `Activate()` / `InitGameMode()` or via a timer. If Dota throws `Script Runtime Error: error in error handling`, wrap the root require in `pcall` to expose the true hidden stack trace.
- Datadriven `SpawnUnit` duplicate key bug: In `ability_datadriven`, defining multiple `"SpawnUnit"` actions in the same event block causes the engine to evaluate all of them using the parameters of the last entry. Spawning multiple distinct units must be handled via a Lua script (`RunScript` or Lua ability).
- Dynamic unit spawning (`CreateUnitByNameAsync`): Always prefer `CreateUnitByNameAsync` over synchronous `CreateUnitByName` when dynamically spawning units. Synchronous creation fails to stream assets in time—breaking not just wearables (`AttachWearables`) and hero base models (e.g. Juggernaut appearing naked or with red ERROR feet), but also skill particle effects, ambient effects, and attachment points.
- Round-pass statue `npc_dota_badguys_fillers_custom` is added to `_vEnemiesRemaining` by unit name in `aohgameround.lua`, so it does not need to spawn on `DOTA_TEAM_BADGUYS` to hold round progression.
- Repeated KV `precache` keys can be lost when traversing `LoadKeyValues` tables. Keep `hack/precache_lua_res.lua` explicit even for effects already listed in KV; refresh it with `python tools/update_precache_manifest.py --write` (omit `--write` to verify). The tool follows active KV includes and validates compiled assets against this addon and Dota/core VPKs.
- Custom item icons use `panorama/images/items/<name>_png.vtex_c` and texture name `item_<name>` for both the item and modifier. Keep the PNG and VTEX source, compile the VTEX in the Workshop Tools content addon with `resourcecompiler.exe`, and copy the compiled texture into this addon; compiling the PNG directly is unsupported.
- Craftable Stygian Desolator keeps `item_desolator_2` for addon recipes and guides. Its native base class and modifier use the new `stygian_desolator` name.
- Pendant Delay uses the native courier cast event and a visible modifier to show and store its delay. Manual cast and Aghanim autocast share `GetChannelTime()`. Keep the ceiling at 9s for the 10s team-wipe countdown.
- Aegis of Infinity and Consumable Aegis share the engine reincarnation hook in `items/custom/item_aegis_lua.lua`. Infinity stores the cumulative attribute bonus when each stack is earned. Pendant autocast checks `IsReincarnating()`. Preserve the level-101 Cosmos execution bypass.
- `ArmSpawnProtection` in `aohgamemode.lua` identifies the main hero via `GetSelectedHeroEntity` and applies the 7s and 2s buffs once per spawn. `RunSpawnCallback` logs failures without `debug`. Watch reincarnations until the hero is alive. The 2s Aegis Spawn Protection buff blocks damage and provides a 1 HP floor. The persistent modifier covers the gap before it is applied. The fallback revive still has a one-second window. Use the death event or Aegis proc to distinguish a new reincarnation from a lingering engine flag. Keep native reincarnation separate from fallback revives and preserve the kill command and Cosmos bypasses.
- The wipe countdown continues through revives. An active Juggernaut Sword Master challenge clears the countdown and blocks new countdowns until the boss's 420s modifier ends.
- Arcade error handlers must run without Lua `debug`. Use `lib/script_error.lua` to preserve plain error messages and table payloads with a `str` field.
- Hired Goon uses `SpawnPlayerHelp` with nil owner arguments. Native creation crashed with owners passed in, so assign the hero owner and player control in the callback. Guard initializes the loadout after ownership is assigned. Owner Buff syncs its base damage bonus for the HUD and buff tooltip.
- Top Underdog rankings are loaded only from the bundled play counts in `played_heroes.lua`. Keep startup and spawn handling independent of HTTP.
